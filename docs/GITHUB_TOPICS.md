# Suggested GitHub Topics / Tags

Add these under the repository's **About → Topics** field to maximise discoverability in GitHub search and topic pages. GitHub allows up to 20 topics; the list below is prioritised — use all of them if possible.

```
powershell
sysadmin
it-administration
microsoft-365
m365
azure
azure-cloud
microsoft-intune
endpoint-manager
sccm
configmgr
azure-virtual-desktop
avd
entra-id
azure-ad
identity-management
automation
cloud-automation
security-tools
dashboard
```

## Notes

- `microsoft-365` and `m365` are both included since community search behaviour varies between the two.
- `sccm` and `configmgr` are both included for the same reason (Configuration Manager is commonly searched under either term).
- Keep this list updated as new tool categories are added (e.g., add `powerbi` or `graph-api` if dashboard/reporting tools expand in that direction).
- Avoid overly generic single-word topics (`tools`, `scripts`) that dilute discoverability — specificity drives better community adoption.
