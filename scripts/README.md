# /scripts

Single-purpose, self-contained PowerShell scripts, organised by category subfolder as the collection grows, for example:

```
/scripts
  /Microsoft365
  /Azure
  /Intune
  /SCCM
  /AVD
  /EntraID
  /Security
  /Automation
```

Every script must follow the [Standard Script Header Template](../docs/SCRIPT_HEADER_TEMPLATE.md) and include comment-based help.
